# ติดตั้ง Apps Script สำหรับ HR Paper Mill (ผู้ใช้สิทธิ์ + Dashboard เจ้าหน้าที่)

ไฟล์ทั้งหมดในโฟลเดอร์นี้ต้องอยู่ในโปรเจกต์ Apps Script เดียวกัน (DoubleA_App ที่ผูกกับ Google Sheets)

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | API ของผู้ใช้สิทธิ์ (login / history / submit / image) และตัวกระจายคำสั่ง — **วางแทนของเดิม** |
| `Schema.gs` | โครงสร้างแผ่นงาน, `setup()`, Log, ฟังก์ชันช่วย |
| `Auth.gs` | เข้าสู่ระบบเจ้าหน้าที่ด้วย Google / LINE, session, สิทธิ์ |
| `Staff.gs` | API ของ Dashboard: ภาพรวม, รายงาน, ตัวกรอง, แก้ไข, ผู้ใช้สิทธิ์ |
| `Admin.gs` | จัดการบัญชีเจ้าหน้าที่ และดู Log |
| `Export.gs` | ส่งออก Google Sheets |
| `Notify.gs` | การแจ้งเตือน: Web Push (มือถือ/คอม) + อีเมลสรุปประจำวัน, ตั้งเวลาเตือน (ดูข้อ 7) |
| `Analytics.gs` | สถิติการใช้งานแบบไม่ระบุตัวตน (หน้าผู้ใช้สิทธิ์ · Staff · ใบเสนอราคา) เก็บในชีต `Analytics` (สร้างให้อัตโนมัติ) · ดูที่แท็บ "สถิติ" ของผู้ดูแลระบบ · ลบข้อมูลเก่ากว่า 400 วันทุกเช้า |
| `Threats.gs` | ตรวจจับพฤติกรรมเสี่ยง (ไล่เดารหัส, เดารหัสสำเร็จ, บอท, ส่งข้อมูลท่วม ฯลฯ) ติดป้ายในชีต `Threats` และส่งอีเมลถึง `ADMIN_EMAILS` ทันทีเมื่อระดับวิกฤต/สูง · บล็อกเครื่องได้ที่หน้า Staff › ผู้ดูแลระบบ › ความปลอดภัย |

`Index.html` เดิมใช้ต่อได้ ไม่ต้องแก้

---

## 1. เพิ่มไฟล์และรัน `setup()`

1. เปิด Apps Script → วางโค้ด `Code.gs` ใหม่แทนของเดิม
2. กด **+ → Script** สร้างไฟล์ `Schema`, `Auth`, `Staff`, `Admin`, `Export`, `Notify` แล้ววางโค้ดตามชื่อไฟล์
3. เลือกฟังก์ชัน **`setup`** แล้วกด **Run** → กด Allow เมื่อระบบขอสิทธิ์ (Sheets, Drive, การเชื่อมต่อภายนอก, อีเมล)
   - สร้างแผ่นงาน `Staff` และ `Logs`
   - เติมหัวคอลัมน์ใหม่ให้ `Users` (E–L) และ `Records` (K–O) **โดยไม่แตะข้อมูลเดิม**

## 2. ตั้งค่า Script Properties

Project Settings (รูปเฟือง) → **Script properties** → Add script property

| Property | จำเป็น | ค่า |
|---|---|---|
| `ADMIN_EMAILS` | ✔ | อีเมล Google ของผู้ดูแลระบบคนแรก (คั่นด้วย `,`) — เข้าสู่ระบบครั้งแรกแล้วเป็น Admin ทันที |
| `GOOGLE_CLIENT_ID` | ✔ (ถ้าใช้ Google) | Client ID จากข้อ 3 |
| `LINE_CHANNEL_ID` | ✔ (ถ้าใช้ LINE) | Channel ID จากข้อ 4 |
| `LINE_CHANNEL_SECRET` | ✔ (ถ้าใช้ LINE) | Channel secret จากข้อ 4 (เก็บที่นี่เท่านั้น ห้ามใส่ในเว็บ) |
| `LINE_REDIRECT_URIS` | – | ค่าเริ่มต้น `https://bysoftlight.github.io/hr-paper-mill/staff.html` (ถ้าเคยตั้งค่านี้ไว้เป็นลิงก์เดิม ให้แก้เป็นลิงก์นี้) |
| `EXPORT_FOLDER_ID` | – | โฟลเดอร์ Drive สำหรับเก็บไฟล์ Google Sheets ที่ส่งออก |
| `ANOMALY_RADIUS_M` | – | ระยะ (เมตร) ห่างจากจุดขายที่ถือว่า "ตำแหน่งผิดปกติ" ค่าเริ่มต้น 300 |
| `SUMMARY_EMAILS` | – | อีเมลรับสรุปรายวัน (คั่นด้วย `,`) |
| `PROFILE_FOLDER_ID` | – | โฟลเดอร์ Drive เก็บรูปโปรไฟล์ที่อัปโหลดจาก Dashboard (ค่าเริ่มต้น `1-GZAWmJ0daUrM6R9HuiayZzRBQwu_-HE`) |
| `REPORT_EMAILS` | – | อีเมลผู้บริหารที่รับ **รายงานประจำเดือน** อัตโนมัติทุกวันที่ 1 (คั่นด้วย `,` — ถ้าไม่ตั้ง ใช้ `SUMMARY_EMAILS` แล้ว `ADMIN_EMAILS`) |
| `GPS_ACCURACY_MAX` | – | ความคลาดเคลื่อน GPS (เมตร) ที่เกินนี้ถือว่า "GPS ไม่แม่น" ค่าเริ่มต้น 100 |
| `NOTIFY_REMIND_HOUR` | – | ชั่วโมงที่เตือนผู้ใช้สิทธิ์ที่ยังไม่ส่ง ค่าเริ่มต้น 17 (รัน `installNotifyTriggers` ใหม่หลังเปลี่ยน) |
| `COMPANY_NAME`, `COMPANY_ADDRESS`, `COMPANY_TAX_ID`, `EMPLOYER_ACCOUNT_NO`, `COMPANY_CONTACT` | – | ข้อมูลสถานประกอบการที่พิมพ์ใน **รายงานมาตรา 35** (ไม่ตั้ง = เว้นช่องให้กรอกเอง) |
| `SESSION_DAYS` | – | จดจำการเข้าสู่ระบบของเจ้าหน้าที่กี่วันนับจากการเปิดเว็บครั้งล่าสุด (ค่าเริ่มต้น 90, สูงสุด 365) |

`SESSION_SECRET` ถูกสร้างให้อัตโนมัติ — ถ้าเปลี่ยนค่า ทุกคนจะต้องเข้าสู่ระบบใหม่

## 3. Google Sign-In (Google Cloud Console)

1. https://console.cloud.google.com → เลือก/สร้างโปรเจกต์
2. **APIs & Services → OAuth consent screen** → External → กรอกชื่อแอปและอีเมล → Scopes: `openid`, `email`, `profile`
3. **Credentials → Create credentials → OAuth client ID** → Application type: **Web application**
4. **Authorized JavaScript origins**: `https://bysoftlight.github.io` (ใส่เฉพาะโดเมน ไม่ต้องมี `/hr-paper-mill`)
5. คัดลอก **Client ID** ไปใส่ `GOOGLE_CLIENT_ID`

## 4. LINE Login (LINE Developers Console)

1. https://developers.line.biz/console/ → สร้าง Provider → **Create a LINE Login channel**
2. แท็บ **LINE Login** → Callback URL: `https://bysoftlight.github.io/hr-paper-mill/staff.html` → เปิดใช้ Web app
3. แท็บ **Basic settings** → คัดลอก **Channel ID** และ **Channel secret**
4. (ไม่บังคับ) ขอสิทธิ์ **OpenID Connect → Email address permission** ถ้าต้องการอีเมลของผู้ใช้ LINE (ใช้แชร์ไฟล์ Google Sheets ที่ส่งออก)
5. เปลี่ยนสถานะ channel เป็น **Published** เมื่อพร้อมใช้งานจริง

## 5. Deploy

**Deploy → Manage deployments → Edit (ดินสอ) → Version: New version → Deploy**
(Execute as: Me · Who has access: Anyone) — URL เดิมไม่เปลี่ยน

## ตรวจสุขภาพระบบ

เปิด `<URL ของ Web app>?health=1` ในเบราว์เซอร์ (URL ที่ลงท้ายด้วย `/exec`) — ต้องเห็น `"success": true`
- `files` เป็น `false` = ไฟล์นั้นยังไม่ได้วางโค้ดรุ่นล่าสุด
- `sheets` เป็น `false` = ยังไม่ได้รัน `setup()`
- `folders` เป็น `false` = บัญชีที่ Deploy เปิดโฟลเดอร์ Drive นั้นไม่ได้
- ถ้าเห็นหน้า error ของ Google แทน JSON ดูวิธีแก้ในหัวข้อถัดไป

### ถ้าหน้าเว็บขึ้น "เชื่อมต่อระบบไม่สำเร็จ" / "ระบบหลังบ้านขัดข้อง"
1. ในโปรเจกต์ต้องมีเฉพาะไฟล์ `Code`, `Schema`, `Auth`, `Staff`, `Admin`, `Export` (+ `Index.html`) — **ลบไฟล์สำรองหรือไฟล์เก่าที่คัดลอกไว้** (ชื่อตัวแปรซ้ำทำให้ทั้งระบบหยุดทำงาน)
2. เลือกฟังก์ชัน `setup` แล้วกด **Run** → ถ้าระบบขอสิทธิ์ ให้กด Allow
3. **Deploy → Manage deployments → Edit → New version → Deploy** (Execute as: Me · Who has access: Anyone)
4. เมนู **Executions** (รูปนาฬิกาซ้ายมือ) แสดงข้อความ error ล่าสุดของ `doPost`

## 6. ข้อมูลที่ควรเติมในแผ่น `Users`

| คอลัมน์ | ใช้ทำอะไร |
|---|---|
| E จุดขาย | กรองตามจุดขาย, แสดงในรายงาน |
| F–G พิกัดจุดขาย | ตรวจ "ตำแหน่งผิดปกติ" (ห่างจากจุดขายเกิน `ANOMALY_RADIUS_M`) — ใน Dashboard กด "ใช้พิกัดจากรายงานล่าสุด" ได้ |
| H เบอร์โทร | ปุ่มโทรในรายชื่อ "ยังไม่ส่งวันนี้" |
| I ใช้งาน | `FALSE` = ปิดใช้งาน (เข้าสู่ระบบส่งรายงานไม่ได้) |

แก้ผ่านหน้า **ผู้ใช้สิทธิ์** ใน Dashboard ได้เลย ไม่ต้องแก้ในชีต

**รูปโปรไฟล์ (คอลัมน์ D):** ในฟอร์มผู้ใช้สิทธิ์ วางลิงก์ Google Drive / ลิงก์รูปได้เลย หรือกด **อัปโหลดรูป**
→ ระบบย่อรูปแล้วบันทึกลงโฟลเดอร์รูปโปรไฟล์ชื่อ `IMG_<รหัส>` (เช่น `IMG_UN1234`) และใส่ลิงก์ลงคอลัมน์ D ให้อัตโนมัติ
อัปโหลดซ้ำ = แทนที่รูปเดิม (ไฟล์เก่าย้ายไปถังขยะ) · บัญชีที่ Deploy ต้องมีสิทธิ์ **แก้ไข** โฟลเดอร์นี้

## 7. การแจ้งเตือน (Push บนมือถือ/คอม + อีเมล)

1. เพิ่มไฟล์ **`Notify.gs`** ในโปรเจกต์ Apps Script (และอัปเดต `Code.gs`, `Staff.gs`, `Export.gs`) แล้ว Deploy เวอร์ชันใหม่
2. รันฟังก์ชัน **`installNotifyTriggers`** หนึ่งครั้ง (เลือกฟังก์ชันด้านบนแล้วกด Run) — รันซ้ำได้ ไม่สร้างซ้ำ ระบบจะ
   - สร้างแผ่น `Notify` และกุญแจ `VAPID_PRIVATE` / `VAPID_PUBLIC` ใน Script Properties — **ห้ามแก้หรือลบ** (ถ้าลบ ทุกเครื่องต้องเปิดการแจ้งเตือนใหม่)
   - **07:00** ตรวจสุขภาพระบบ (ไฟล์ แผ่นงาน โฟลเดอร์ ตัวตั้งเวลา ข้อผิดพลาดจากเครื่องผู้ใช้) — พบปัญหาส่งอีเมลถึง `ADMIN_EMAILS`
   - **17:00** เตือนผู้ใช้สิทธิ์ที่ยังไม่ส่งรายงาน (`NOTIFY_REMIND_HOUR`)
   - **18:00** สรุปประจำวันให้เจ้าหน้าที่ (push + อีเมลของเจ้าหน้าที่ที่เลือกรับ + `SUMMARY_EMAILS`)
   - **วันที่ 1 เวลา 08:00** รายงานประจำเดือน (เทียบเดือนก่อน) ส่งอีเมลพร้อม PDF ถึง `REPORT_EMAILS`
3. ผู้ใช้เปิดเองที่ **บัญชี › ตั้งค่า › การแจ้งเตือน**
   - ผู้ใช้สิทธิ์: เตือนเมื่อยังไม่ได้ส่งรายงาน
   - เจ้าหน้าที่: รายงานใหม่ (ทันทีที่มีคนส่ง) · สรุปประจำวัน · สรุปประจำวันทางอีเมล (บัญชี Google)

**เครื่องที่รองรับ:** Android (Chrome/Edge/Samsung Internet) และคอมพิวเตอร์ ได้รับแม้ปิดเว็บอยู่ · **iPhone/iPad (iOS 16.4+) ต้อง "เพิ่มไปยังหน้าจอโฮม" จาก Safari แล้วเปิดจากไอคอนก่อน** (หน้าตั้งค่าจะแสดงขั้นตอนให้)

เบื้องหลัง: ระบบเก็บข้อความไว้ในแผ่น `Notify` แล้วส่ง push เปล่าไปปลุกเครื่อง → `sw.js` ของเว็บดึงข้อความ (`notify.inbox`) มาแสดง · เครื่องที่ยกเลิก/ลบแอป (ตอบ 404/410) ถูกลบออกจากแผ่นอัตโนมัติ · ผลการส่งแต่ละวันบันทึกใน `Logs` (`system.notify_remind`, `system.daily_summary`)

> รุ่นเดิมที่ใช้ `installDailySummaryTrigger` ยังทำงานได้ แต่แนะนำให้รัน `installNotifyTriggers` แทน (ตั้งเวลาให้ครบทั้งสองอย่างและไม่ซ้ำกัน)

## ระบบสิทธิ์

- บัญชีใหม่ (Google หรือ LINE) = **รออนุมัติ** ไม่เห็นข้อมูลใดๆ จนกว่า Admin จะอนุมัติในหน้า **ผู้ดูแลระบบ**
- บทบาท: **Viewer** (ดู) · **Editor** (ดู + เพิ่ม/แก้/ลบ + จัดการผู้ใช้สิทธิ์ + ส่งออก) · **Admin** (ทุกสิทธิ์ + จัดการบัญชี + Log)
- ปรับสิทธิ์รายข้อได้ และการเปลี่ยนสิทธิ์/ระงับบัญชีมีผลทันทีโดยไม่ต้องให้ผู้ใช้ออกจากระบบ
- ระบบไม่ยอมให้ Admin คนสุดท้ายถูกลดสิทธิ์หรือลบ และไม่ให้ Admin ลดสิทธิ์ตัวเอง
- ทุกการแก้ไข ลบ อนุมัติ ส่งออก และการเข้าสู่ระบบ ถูกบันทึกในแผ่น `Logs`
- เจ้าหน้าที่กด **บัญชี › ออกจากระบบทุกอุปกรณ์** ได้เอง (เช่น ลืมออกจากระบบในเครื่องอื่น) token เดิมทุกเครื่องใช้ไม่ได้ทันที และบันทึกใน Log เป็น `staff.logout_all` — ต้องใช้ `Staff.gs` ตั้งแต่ v3.15 ขึ้นไป (รุ่นก่อนหน้า เว็บจะแจ้งให้ผู้ดูแลอัปเดต)

## หน้าตั้งค่า (เว็บ v3.15)

การตั้งค่าในหน้า **บัญชี › ตั้งค่า** (และ "ตั้งค่าการแสดงผล" ในหน้าเข้าสู่ระบบ) จำไว้ในเบราว์เซอร์ของแต่ละเครื่อง ไม่ได้เก็บในชีต:

- ทุกคน: ธีม (ตามเครื่อง/สว่าง/มืด) · ขนาดตัวอักษร (ปกติ/ใหญ่/ใหญ่มาก) · ลดภาพเคลื่อนไหว
- ผู้ใช้สิทธิ์: สถานะสิทธิ์ GPS + ปุ่มทดสอบ · คุณภาพรูปหลักฐาน (ประหยัดเน็ต 800px / มาตรฐาน 1024px / คมชัด 1600px) · จดจำการเข้าสู่ระบบ (ปิด = จำเฉพาะแท็บนี้) · ล้างข้อมูลที่เก็บในเครื่อง
- เจ้าหน้าที่: หน้าแรกหลังเข้าสู่ระบบ · ความถี่อัปเดตรายการใหม่ (20 วิ/1 นาที/5 นาที/ปิด) · จำนวนรายการต่อหน้า · แสดงรูปย่อในตาราง

## สิ่งที่เพิ่มในเวอร์ชัน 3.20

- **ตรวจหลักฐานอัตโนมัติ**: รูปซ้ำ (ลายนิ้วมือรูปเหมือนกันข้ามวัน/ข้ามคน) และ GPS ไม่แม่น (> `GPS_ACCURACY_MAX`) — แสดงป้ายในหน้ารายงาน/ภาพรวม และกรอง "ต้องตรวจสอบทั้งหมด" ได้ (ตรวจได้เฉพาะรายงานที่ส่งจากแอปเวอร์ชันนี้ขึ้นไป เพราะรูปเก่าไม่มีลายนิ้วมือ)
- แผ่น `Records` มีคอลัมน์ใหม่ P–R: ความแม่นยำ GPS, ลายนิ้วมือรูป, เวลาที่ระบบได้รับ (เพิ่มหัวคอลัมน์ให้อัตโนมัติ)
- **บันทึกการติดต่อ** (โทรแล้ว/ไม่รับสาย/แจ้งเหตุผล/ลงพื้นที่) เก็บในแผ่น `Contacts` (สร้างอัตโนมัติ)
- **รายงานสำเร็จรูป** ในหน้า รายงาน › ส่งออก: รายงานประจำเดือน (ดู/PDF/Excel/ส่งอีเมลตอนนี้) และรายงานการให้สิทธิ์ตามมาตรา 35 ประจำปี (ดู/PDF/Excel) — ช่องเลขประจำตัวประชาชนและประเภทความพิการระบบไม่ได้เก็บ ให้กรอกเอง และตรวจรูปแบบกับหน่วยงานที่ยื่นก่อนส่ง
- **ข้อผิดพลาดบนเครื่องผู้ใช้** (เช่น ปุ่มค้างบน Safari, เข้าสู่ระบบไม่ได้เพราะเน็ต) ส่งเข้า `Logs` เป็น `client.error` พร้อมชื่อผู้ใช้ หน้า และโหมดแอป — กรองได้ที่ ผู้ดูแลระบบ › Logs › "ข้อผิดพลาดบนเครื่องผู้ใช้"
